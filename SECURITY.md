# Security Policy

## Supported Versions

Only the latest version of this DWM fork is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability, please do not open a public issue or pull request. Report it through GitHub's private vulnerability reporting feature when enabled, or contact the maintainers privately.

See the [security notes](./docs/src/security.md) for the project's threat-model limitations and configuration guidance.
